# Workshop Facilitation

Use this as a support protocol for interactive advisory skills.

## Entry

Briefly state the workshop outcome and offer these entry modes when user choice is necessary:

- Guided: one question at a time.
- Context dump: user supplies existing material first.
- Best guess: proceed from evidence and mark assumptions.

## Turn Protocol

1. Ask one material question per turn.
2. Use plain language and two or three meaningful choices when choices clarify a real tradeoff.
3. Label progress, such as `Context 2/5` or `Scoring 3/5`.
4. Summarize the answer into a compact decision ledger; do not replay the full conversation.
5. If interrupted, answer the interruption, preserve the current step, and resume without restarting.
6. At decision points, number recommendations and place the recommended default first.
7. Stop asking when remaining unknowns are discoverable, low impact, or safely covered by a stated default.

## Completion

Return the result, evidence, open risks, next actions, and assumptions. The final artifact must stand alone without requiring the user to reread the workshop transcript.
